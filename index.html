Arsitektur Von Neumann

Arsitektur Von Neumann adalah model dasar arsitektur komputer yang dirancang oleh John von Neumann pada tahun 1945. Model ini menjadi dasar pembahasan komputer modern: Input → CPU ↔ Memori → Output.

CPUMenjalankan instruksi dan melakukan operasi aritmatika serta logika.
MemoriTempat menyimpan data dan instruksi program.
InputMemasukkan data ke komputer, misalnya keyboard dan mouse.
OutputMenampilkan hasil pemrosesan, misalnya monitor dan printer.

Contoh: saat kamu mengetik kalimat, keyboard memasukkan data, komputer memprosesnya, lalu monitor menampilkan hasilnya.

CPU: pusat pemrosesan

CPU (Central Processing Unit) sering disebut “otak” komputer karena bertugas menjalankan instruksi dari program.

ALUArithmetic Logic Unit, melakukan perhitungan dan operasi logika.
Control UnitMengatur alur instruksi yang harus dijalankan.
RegisterPenyimpanan data kecil dan cepat di dalam CPU.
Bayangkan: ALU seperti bagian yang menghitung, Control Unit seperti pengatur pekerjaan, dan Register seperti tempat kecil untuk menaruh informasi yang sedang dipakai.

Memori: RAM dan ROM

Memori menyimpan data dan instruksi program.

RAM (sementara)Dipakai saat program berjalan. Data hilang ketika komputer dimatikan.
ROM (permanen)Menyimpan instruksi dasar yang diperlukan saat komputer dinyalakan (nonvolatile).
HDD dan SSDContoh penyimpanan sekunder yang tetap menyimpan data tanpa listrik.
Ingat: RAM bukan tempat menyimpan file secara permanen. HDD dan SSD tidak sama dengan ROM, tetapi sama-sama nonvolatile.

Perangkat input dan output

Input adalah cara komputer menerima data, contohnya keyboard, mouse, scanner, dan microphone.

Output adalah cara komputer menyampaikan hasil kepada pengguna, contohnya monitor, printer, dan speaker.

Alurnya: Input → Proses → Output

Siklus instruksi

Siklus instruksi adalah proses yang dilakukan CPU untuk menjalankan satu instruksi program, dan terjadi berulang kali saat program berjalan.

1. FetchCPU mengambil instruksi dari memori dan menyimpannya di register.
2. DecodeCPU menerjemahkan instruksi agar bisa dipahami bagian yang menjalankannya.
3. ExecuteCPU menjalankan instruksi: menghitung, membandingkan, atau memindahkan data.
Store (opsional)Hasil eksekusi disimpan kembali ke memori jika diperlukan.

Contoh: instruksi “Tambah 5 + 3”. CPU mengambil instruksi, menerjemahkannya sebagai penjumlahan, lalu menghitungnya.

Sistem operasi

Sistem operasi (Operating System/OS) adalah perangkat lunak sistem yang mengelola sumber daya perangkat keras dan perangkat lunak, serta menyediakan layanan bagi program aplikasi. OS menjadi penghubung antara pengguna, aplikasi, dan perangkat keras. Contohnya Windows, macOS, Linux, Android, dan iOS.

Manajemen memoriMengatur alokasi RAM untuk program yang berjalan.
Manajemen fileMengatur penyimpanan, pengorganisasian, dan penamaan file.
Manajemen prosesMengatur penjadwalan dan eksekusi program.
Manajemen input/outputMengatur komunikasi perangkat input/output dengan sistem.
Pengguna dan keamananMengelola akun, hak akses, dan membantu melindungi sistem.

Contoh sehari-hari: saat membuka kamera di smartphone, OS membantu aplikasi memakai kamera, memori, prosesor, dan layar.

Alur kerja dan ringkasan

Saat mengetik di keyboard:

  1. Input: keyboard menerima ketikanmu.
  2. Proses: CPU menjalankan fetch, decode, dan execute.
  3. Memori: data dan instruksi yang diperlukan disimpan sementara di RAM.
  4. Output: monitor menampilkan hasil.
  5. Sistem operasi: mengatur proses, memori, file, serta perangkat input/output.
Inti pemahaman: komputer bukan sekadar CPU, melainkan sistem dari banyak komponen yang saling berhubungan.

Refleksi: bagaimana data berpindah dari keyboard hingga tampil di monitor? Apa yang terjadi jika komputer tidak punya sistem operasi?
